# Mariano Araujo

**AI-driven infrastructure and automation | Linux, k3s, Python | LLM integration and safe, reliable operations**

[Versión en español](README.es.md)

I put AI to work on real projects: on self-hosted infrastructure, with minimal permissions and every decision
documented. Here I share how I do it and what I have learned along the way, in case it helps someone else.

## Cases

| Case | What it shows |
|---|---|
| [AI Split Raspberry Pi](https://github.com/marianoa73/ai-split-raspberry-pi) | Modular split of tasks between three AI assistants and a self-hosted model on a Raspberry Pi: model choice, human validation, monitoring, failures and recovery |
| [Family Savings](https://github.com/marianoa73/family-savings) | A small family bank web app that teaches kids to save: achievements with a visible reward, adult approval, goals and withdrawals |
| [AI Animated Shorts](https://github.com/marianoa73/ai-animated-shorts) | 3D animated shorts produced on self-owned hardware: voices cloned from your own samples, automatic audio checking with Whisper, three.js rendering and human review before publishing |
| Linux monitoring (in preparation) | Multi-host monitoring with minimal permissions |
| Task notifications (in preparation) | Task → queue → dashboard → alert, without duplicates |

All repositories are MIT-licensed and documented in English and Spanish.
