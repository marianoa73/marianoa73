## Cómo trabajo

- **Primero local:** las caras, las voces y los datos personales se quedan en mis propios equipos.
- **Una persona aprueba** lo importante: cortes, publicaciones, todo lo que no se puede deshacer.
- **Las estimaciones se llaman estimaciones** hasta que las mido.
- **Cada decisión queda escrita**, con sus límites.
